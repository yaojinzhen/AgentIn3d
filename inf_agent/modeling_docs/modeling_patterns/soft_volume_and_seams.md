# 柔性体块与缝线

直接构造静态结果，不默认引入布料模拟。控制笼应先表达填充体积、面片边界、角部约束和压缩区；
细分负责平滑，但必须保留接缝和角部控制。下垂与不对称使用低幅度、低频率形变。

接缝、滚边、下摆、绑带和扣点在可见时属于识别结构，应由面片边界或表面曲线计算，始终与承载体
贴合。褶皱应沿压缩和连接方向产生；均匀分布的随机噪声通常会呈现融化塑料感。

织物、皮革等材质由材质卡负责。本卡只保留几何层和表面附着约束。

## 方法专属验证

正交轮廓应表现可信填充和压缩，不能保留明显 primitive 直角；透视图检查软性高光流、缝线和滚边
贴合。若主体仍像圆角方块，应先调整控制笼、面片边界和压缩区，再增加褶皱或表面细节。
