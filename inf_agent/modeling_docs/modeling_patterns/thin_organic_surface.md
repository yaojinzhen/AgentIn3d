# 薄片有机表面

以中心线坐标 `u`、半宽函数 `w(u)` 和结构化的弯曲或扭转定义薄片。宽度通常从基部收窄，经过主要
展开区后向尖端收束；卵形、披针形、心形或花瓣形需要不同的宽度曲线，不能由统一矩形近似。

## 核心构造

1. 沿中心线建立相互对应的左右边界和内部条带。
2. 以低幅度加入 camber、curl、bend 和轻微不对称，避免完全平面。
3. 将叶柄、花柄或连接柄从基部中心线延伸，并与主体形成真实接触。
4. 主脉和分支纹理应服从共同坐标系，分支尺度逐渐减小并在边界前合理终止。
5. 只有影响最终轮廓的锯齿或裂片才使用真实边界几何。

大量分支或边缘重复可以使用 Geometry Nodes；单个简单薄片通常使用自定义网格加曲线更直接。

## 方法专属验证

顶面检查尖端、基部、边缘和分支布局；侧面与透视图检查弯曲、厚度和法线；正面检查钝矩形尖端与
脱离的连接柄。导出前确认薄表面的双面显示或实际厚度符合目标格式。
