# 圆润有机体

先用纬向轮廓、截面环或有序网格确定高度宽度比、最大半径位置、肩部、底部和极点。细分和噪声只能
丰富已经正确的结构，不能把普通 UV sphere 变成具有明确种类特征的有机体。

## 核心构造

1. 确定主比例、重心和轮廓转折。
2. 单独塑造顶部和底部，避免深而规则的孔洞或夹点。
3. 以小于主轮廓特征的幅度加入低频不对称。
4. 从主体表面坐标计算果梗、柄、蒂或其他附件的锚点，并保留少量合理嵌入。
5. 最后增加不会改变轮廓的细微表面变化。

苹果、梨或浆果的具体原生 Factory、颜色与表皮实现属于对象卡和材质卡，本卡不重复这些资产事实。

## 方法专属验证

正面和侧面验证比例、肩部和不对称；顶面验证极点及附件位置；透视图验证轮廓过渡和接触。若形态仍
像普通球体或规则南瓜，应修改结构轮廓，而不是增加细分、瓣数或高频噪声。
