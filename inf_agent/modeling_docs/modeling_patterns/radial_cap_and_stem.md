# 径向伞盖与支撑柄

用径向侧轮廓定义冠部高度、边缘下垂或上翘、边缘厚度和下表面。支撑柄需要合理的收放和轻微弯曲，
其顶部应进入或过渡到伞盖下表面；可见间隙或刚好一点相切都会使两者像独立 primitive。

## 次级结构

菌褶、孔洞或径向折叠从柄部附近向外延伸并服从伞盖表面。数量和厚度应与预览尺度匹配，并在边缘
前正确裁剪；单个深色圆盘不能代替真实下表面。只有在大量径向元素需要共享分布规则时才使用
Geometry Nodes。

低频伞盖不对称和边缘变化应在主轮廓正确后添加。斑点、鳞片、菌环等对象特征是受控附加层，不能
用随机团块统一代替。具体蘑菇原生模块和物种事实由对象参考卡负责。

## 方法专属验证

正面和侧面验证伞盖轮廓、柄部收放和连接；顶面检查径向不对称；透视图应在可见角度呈现可信下表面。
先修复伞盖与柄的连接，再增加菌褶或表面细节。
