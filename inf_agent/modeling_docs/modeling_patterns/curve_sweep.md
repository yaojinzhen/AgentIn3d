# 曲线扫掠

先在承载部件的局部坐标系中确定中心路径。把手应从一个安装面连接到另一个安装面；线缆应从接口
连接到插头或明确的截断端。圆形截面可使用曲线 bevel，非圆截面可沿路径建立有序截面环。

## 核心构造

- 使用少量具有结构意义的控制点，避免密集随机点造成折角。
- 弯曲半径应明显大于截面半径；只有真实截面变化时才使用 taper。
- 矩形或扁平截面需要控制 tilt，必要时使用平行移动标架避免截面翻转。
- 端点应略微进入承载面，或通过套环、插座、支架和端盖解释连接。
- 仅在导出或后续拓扑处理需要时将曲线求值或转换为网格。

Geometry Nodes 适合大量线束、缝线或肋条的场驱动分布。单个把手或单根线缆通常直接使用曲线即可。

## 方法专属验证

从正面和侧面检查路径，从顶面检查意外横向偏移，从透视图检查两个端点。重点排查急弯自相交、
截面滚转、变换后粗细变化、未封口端点和可见悬空。增加曲线分辨率不能修复错误路径或连接坐标。
