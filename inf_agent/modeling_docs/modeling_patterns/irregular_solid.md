# 不规则实体

从具有明确主轴和支撑面的封闭有序网格开始，再分层添加形变：低频控制偏斜、主要鼓包和质量分布；
中频控制平面、裂隙、侵蚀和层状结构；高频只控制不会改变主轮廓的表面粗糙度。

统一径向噪声通常只会得到带皱纹的球体。应组合方向缩放、底部压平、平面状切削和有界位移。除非
参考物确实以尖点平衡，否则必须保留可信支撑面。网格密度应由目标形变尺度决定，不能用过量细分
掩盖薄弱的宏观形态。

岩石的原生 Factory 和石材材质属于对象卡和材质卡，本卡只描述几何机制。

## 方法专属验证

不同正交视图的轮廓应有差异，但不能出现随机尖刺；透视图应显示连贯的支撑关系和至少两个可读的
形变尺度。强位移后检查法线、自相交和底部稳定性。若整体仍像球体，先修改低频质量分布。
