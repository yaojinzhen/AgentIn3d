# 材质尺度与变化原则

材质节点数量不能证明质量。按以下顺序构造和验证：

1. 符合语义和用户要求的基础色、明度与金属度；
2. 与物体结构或坐标关联的宽幅区域变化；
3. 材料类别对应的粗糙度和高光宽度；
4. 在最终预览中可见但不主导的细微颜色或起伏；
5. 仅在需求明确时增加透射、发光、涂层、磨损等特殊行为。

噪声 scale 不能脱离物体大小直接复用。应检查最终画面中有多少个可见变化周期跨过主体，避免近白
兜底、高对比噪声，以及把同一节点图用于木材、果皮、叶片、金属和石材。把手、内腔、紧固件、
果梗和屏幕等语义区域通常需要独立材质或遮罩。

中性光照下先确认基础色，再检查高光和粗糙度，最后检查纹理尺度与凹凸。最早一层错误时，应修复
该层而不是继续叠加节点。具体材质选择继续查询同目录下的语义材质卡。
